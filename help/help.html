NOTIFICAÇÕES

🔔 Configuração do ntfy

O Monitor SARP utiliza o ntfy para enviar notificações de novos chamados diretamente para o seu celular.

A configuração é simples. Você precisa instalar o aplicativo ntfy, criar um tópico e informar a URL desse tópico nas configurações da extensão.

1. Instale o ntfy no celular

Primeiro, instale o aplicativo ntfy no seu celular.

Depois de instalar, abra o aplicativo e permita que ele envie notificações.

2. Crie um tópico

No aplicativo ntfy, crie um novo tópico para receber as notificações do Monitor SARP.

⚠️ Escolha um nome difícil de adivinhar

O tópico funciona como um endereço para suas notificações. Por isso, evite nomes simples como sarp, monitor ou notificacao.

Prefira um nome exclusivo para reduzir a possibilidade de outras pessoas descobrirem seu tópico.

3. Copie a URL do tópico

Depois de criar o tópico, copie a URL completa dele.

Ela terá um formato semelhante a:

https://ntfy.sh/seu-topico

Essa é a URL que o Monitor SARP utilizará para enviar as notificações.

4. Configure a extensão

Agora abra as configurações do Monitor SARP.

  1. Abra o popup do Monitor SARP.
  2. Clique no ícone de Configurações ⚙.
  3. Localize o campo URL ntfy.
  4. Cole a URL completa do seu tópico.
  5. Clique em Salvar Preferências.
✓ Configuração concluída!

A partir desse momento, quando o Monitor SARP detectar um novo chamado, ele enviará automaticamente uma notificação para o tópico configurado no ntfy.

⚠️ Atenção

Não compartilhe publicamente a URL do seu tópico. Qualquer pessoa que conheça essa URL poderá publicar mensagens nele.

CONFIGURAÇÃO

📱 Configuração recomendada no celular

Para aumentar a confiabilidade das notificações, principalmente quando o celular estiver bloqueado, verifique as seguintes configurações:

  • Permita as notificações do ntfy.
  • Permita notificações na tela de bloqueio.
  • Permita a vibração das notificações.
  • Não bloqueie o funcionamento do ntfy em segundo plano.
  • Caso o seu celular possua configurações de economia de bateria, evite restringir o uso do ntfy.
⚠️ Alguns celulares possuem restrições adicionais

Fabricantes como Xiaomi, Samsung e outros podem aplicar regras próprias de economia de bateria que limitam aplicativos em segundo plano.

Se as notificações demorarem ou não aparecerem com a tela bloqueada, verifique as configurações de bateria e notificações do ntfy no seu aparelho.

✓ Tudo pronto

Com o ntfy configurado corretamente, o Monitor SARP poderá enviar os avisos de novos chamados diretamente para o seu celular.
